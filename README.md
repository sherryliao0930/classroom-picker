# 🐾 動物扭蛋分組機

給國小教室用的隨機分組／抽籤工具，可愛動物童趣風格。

**網址：** https://sherryliao0930.github.io/classroom-picker/

## 功能

- **兩種抽法** — 🎯 單抽一人（上課點人回答）、👥 分組
- **分組彈性** — 指定「分幾組」，每組人數留空就自動平均分完（除不盡也會處理）
- **可重複／不重複** — 不重複＝每人只抽一次；可重複＝抽出後放回
- **一顆一顆揭曉** — 搖機器 → 扭蛋掉出 → 蛋殼彈開 → 名牌飛進隊伍卡，不會一次全開
- **姓名留在畫面上** — 抽出的名字完整顯示在名牌上直到下次轉動
- **隊名** — 五種主題（動物／水果／星際／顏色／運動）可選，也能自己輸入，或直接點卡片上的隊名修改
- **音效** — 六段 WebAudio 即時合成音效，不需音檔，可一鍵靜音
- **上課模式** — 全螢幕放大，適合投影或平板舉起來給全班看
- **一鍵下載** — 分組結果可存成圖片（PNG）或文字檔
- **記住名單** — 名單與設定存在自己的裝置上，下次打開自動帶入，隨時可一鍵清除

## 關於學生名單

**名單不會上傳到任何伺服器。** 網站原始碼裡不含任何學生資料，頁面預設是空白的。

老師把班級名單貼進「學生名單」欄位後，程式會用瀏覽器的 `localStorage` 記在**你自己這台裝置**上，下次打開自動帶入，不必重貼。這份資料從頭到尾留在本機，不會傳送到 GitHub 或其他地方。

共用平板或想清掉資料時，按名單下方的 **🗑️ 清除** 就會刪除這台裝置上記住的名單與設定。

> Safari 無痕模式不允許寫入 `localStorage`，此時畫面會提示「關掉分頁就會消失」，功能仍可正常使用。

名單格式為一行一位：

```
1 王小明
2 陳小華
3 林小美
```

號碼可以省略，直接打名字也行。

## 技術

單一 HTML 檔，無任何外部相依套件或框架，離線可用。下載 `index.html` 直接用瀏覽器開啟即可。
